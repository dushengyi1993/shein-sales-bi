# 成本表导入目录

把用户手动提供的成本表放到本目录，再运行：

```powershell
node .\scripts\import_product_costs.mjs --file .\inputs\costs\你的成本表.xlsx
```

支持 `.xlsx` / `.csv`。

## 成本批次字段建议

成本表一行代表“一个货号的一批货”。字段名不必完全一致，脚本会识别常见中文表头：

- `货号` / `标准货号` / `商品货号`
- `发货申请单` / `批次号`
- `发货数量` / `数量`
- `货款金额` / `商品成本` / `采购成本`
- `头程运输费金额` / `头程运费` / `头程运输费`
- `其他费用`
- `币种`，默认 `CNY`
- 可选：`采购单价`、`长cm`、`宽cm`、`高cm`、`重量kg`

重要：如果某批货缺少 `头程运输费金额`，脚本会把这批标记为“不完整批次”，不会纳入单位成本均摊。

## 月仓储费字段建议

月仓储费可单独放一个 sheet 或 CSV：

- `月份` / `年月`
- `仓储费` / `仓储费金额`
- `币种`，默认 `SAR`
- `备注`

月仓储费只用于月度总利润和 DSY/LGM 分组利润，不拆到单个货号。
