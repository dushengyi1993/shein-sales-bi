## 核心原则

GPT Image 2 不是不能画好看的女性，而是不稳定地接受直白欲望词。电商产品图需要“吸睛但能稳定出图”，所以最终提示词要少写身体刺激，多写高级审美。

正确方向：

- 成年感。
- 气质。
- 姿态。
- 比例。
- 服装剪裁和材质。
- 明亮干净的商业光影。
- 构图和角色设计。
- 商业审美。

错误方向：

- 直接堆 `性感`、`诱惑`、`挑逗`、`胸大`、`翘臀`、`低机位`、`湿身`、`成人写真` 等词。
- 把身体局部当成画面目的。
- 把卧室、浴室、床上等场景写成暧昧私密空间。
- 把甜美/少女感和性感组合在一起。

## 安全审查改写公式

把用户原始想法改写为稳定表达：

```text
敏感欲望词
↓
气质词
↓
体态整体描述
↓
服装得体化
↓
场景明亮化
↓
镜头商业化
↓
加安全边界
```

示例结构：

```text
一位成年女性模特，气质成熟、温柔自信，拥有健康丰腴且比例协调的体态，自然流畅的身体曲线。
她姿态舒展，肩颈线条柔和，腰线自然，整体呈现高级女性美和成熟吸引力。
服装剪裁合身，材质柔软有质感，贴合身体但不过度暴露，整体得体高级。
画面采用明亮干净的商业摄影光线、时尚 editorial 构图和高级电商视觉风格。
重点表现人物气质、服装质感、姿态美感、产品使用场景和品牌商业质感，不突出身体局部，不做挑逗姿态。
```

## 案例提示词的可迁移骨架

这些案例的价值不在于具体人像题材，而在于“写细但不直白”的结构。迁移到电商图时，按这个顺序写：

1. **图像任务声明**：成图类型、比例、画面风格、商业用途，例如 `3:4 电商封面图 / high-end commercial photography / fashion editorial product image`。
2. **主体与构图**：人物和产品在画面中的位置、景别、角度、留白、移动端识别重点。
3. **成人身份与气质**：明确成年模特，写成熟、温柔、自信、清冷、精致、亲和、有故事感等气质。
4. **姿态与整体体态**：写肩颈舒展、身体自然侧转、腰线自然、比例协调、S 型动态姿态；不要把胸、臀、腿等局部当成目的。
5. **脸部、发型、妆容**：写神情、眼神、微笑、妆容干净、发丝质感，增加真实人物吸引力。
6. **服装剪裁与材质**：写合身剪裁、缎面、罗纹、运动面料、针织、柔软布料、轻微光泽；用材质和版型体现吸引力。
7. **场景和光影**：写明亮室内、窗边自然光、柔光、浅景深、干净背景、温暖/清凉/轻奢氛围。
8. **产品回收**：写产品必须清楚、前景/C 位、真实使用动作、手部/视线/身体方向引导到产品。
9. **材质和成图质量**：写高清、真实布料、皮肤质感、头发细节、商业摄影、移动端清晰。
10. **负向边界**：不低俗、不挑逗、不突出身体局部、不低机位身体凝视、不未成年感、不让人物抢走产品。

一句话模板：

```text
生成一张 [比例] 的 [产品品类] SHEIN 电商图，整体是明亮高清的商业摄影 / 时尚 editorial 风格。
画面中一位成年女性模特正在真实使用 [产品]，产品位于前景或 C 位，清楚、较大、可识别，模特的手部动作、视线和身体方向自然引导注意力回到产品。
模特气质成熟、温柔自信、有高级女性美，姿态舒展自然，身体比例协调，曲线自然流畅，服装剪裁合身、材质高级且得体。
场景为 [明亮居家 / 办公室 / 旅行 / 浴室梳妆台 / 健身后放松等]，采用干净柔光、浅景深和高明度色彩，移动端一眼能看懂产品卖点。
画面重点是产品、真实使用结果、人物气质、服装质感和商业氛围，不突出身体局部，不使用挑逗或低俗表达。
```

## 案例里能吸收的“细节密度”

提示词可以比普通电商 prompt 更细，但每一段都要服务产品：

- **人物不是一句“美女”**：要写年龄感、气质、眼神、发型、妆容、服装材质、姿态和动作。
- **姿态不是“更性感”**：要写具体动作，例如自然回望、轻微侧身、肩颈舒展、手臂自然扶住产品、坐姿端正、身体略微转向产品。
- **吸引力不是“暴露”**：优先用合身剪裁、真丝/罗纹/运动面料、露肩/锁骨/上背线条、清透光线和皮肤质感表达。
- **场景不是“背景”**：写时间、光线、道具、空间质感，例如晨光窗边、办公室午休、旅行酒店、明亮卧室、家庭吧台。
- **关键词不是越多越好**：只保留对风格、材质、光影、构图、产品识别有帮助的词。

## 电商图必须去掉 3D 假人感

X 案例多为 3D CG / 二次元角色，这种质感不能直接迁移到 SHEIN 真实电商图。除非用户明确要求插画或 CG，否则默认加真实摄影约束：

```text
highly realistic commercial photography, natural skin texture with subtle real imperfections, realistic fabric texture, believable hands and anatomy, no 3D CG render look, no plastic skin, no fake doll face, no wax-figure look, no AI mannequin look
```

中文执行口径：

- 脸要像真实成年模特，不要像 AI 娃娃脸、充气感假人、蜡像或过度磨皮。
- 皮肤可干净漂亮，但要有自然纹理和轻微真实瑕疵。
- 布料要有真实褶皱、厚薄和材质，不要塑料感。
- 手部必须可信，尤其是按按钮、托住产品、扶住按摩器、握住手柄等动作。

## 沙特市场的得体性感边界

用户可以要流量感，但如果目标是 SHEIN 沙特市场，默认优先“高审美、得体、产品主导”，不要把吸引力压在暴露程度上。

KSA 默认写法：

```text
adult model with mature appeal and high-end feminine beauty, elegant modest clothing, controlled neckline, premium fabric, slightly relaxed drape, polished makeup, bright commercial lighting, product-led posture
```

KSA 默认避免：

- 内衣感、情趣感、透视、湿身、衣服滑落。
- 极深领口、强乳沟、露腹、超短裙、过紧 bodycon。
- 低机位身体凝视、胸/臀/腿局部特写。
- 只为展示身材而存在的托腮、咬唇、撩发、趴姿、跪姿。

如果用户明确要求更大胆，优先加：

- 脸部吸引力、发型、妆容、眼神。
- 真丝、罗纹、运动面料等材质质感。
- 合身但得体的剪裁。
- 明亮光影、清透皮肤质感。
- 真实使用动作和产品 C 位。

不要直接加更多裸露、私密氛围或局部身体强调。

## 案例里要降级或替换的写法

X 案例主要是 3D CG 人像，不是电商图。迁移时必须降级：

- `床上 / 卧室私密感` -> `明亮卧室或居家放松场景，姿态端正，产品使用明确`。
- `泳装 / 湿润水光 / 海边低机位` -> `度假 Lookbook / 清凉运动休闲穿搭 / 正常商业镜头`。
- `女仆、猫耳、幻想角色装` -> `真实可购买的时尚家居服、运动背心、丝缎睡袍、针织衫、轻奢休闲装`。
- `低机位、身体凝视、局部强调` -> `平视或微俯视商业镜头，产品优先，人物姿态自然`。
- `人像海报主导` -> `产品图主导，人像只作为流量入口和场景代入`。

## 负向提示词模板

长版：

```text
避免裸露，避免挑逗动作，避免低俗化表达，避免身体部位特写，避免低机位凝视视角，避免未成年感，避免过度暴露服装。整体以高级角色设计、时尚人像、商业视觉和审美表达为主。
```

短版：

```text
画面保持高级、得体、克制，不做挑逗姿态，不突出身体局部，不使用低俗或成人向表达。
```

更强约束版：

```text
重点表现人物气质、服装质感、姿态美感、光影层次、产品使用场景和商业视觉，不以身体暴露作为画面重点。
```

## 生成前自检

1. 是否明确是成年女性角色。
2. 是否避免“少女感 + 性感”的组合。
3. 是否没有单独强调胸部、臀部等身体局部。
4. 是否没有使用挑逗、诱惑、勾引等词。
5. 是否没有低机位、身体凝视、局部特写。
6. 服装是否写成得体、合身、剪裁优雅。
7. 场景是否明亮、干净、商业化，而不是私密暧昧。
8. 画面重点是否放在气质、姿态、服装、光影、产品和商业质感上。

## 失败后怎么改

### 提示词被拒

先删：

- 性感。
- 挑逗。
- 魅惑。
- 胸、臀。
- 低机位。
- 湿身。
- 暧昧。
- 诱惑。

再换：

- 成熟。
- 优雅。
- 健康。
- 自信。
- 自然曲线。
- 高级女性美。
- 商业人像。
- 得体服装。

### 生成结果太保守

不要加“更性感”。改成：

- 增强人物的时尚表现力。
- 增强高级女性气质。
- 优化身体比例与姿态。
- 让体态更圆润匀称。
- 增强服装剪裁的贴合度。
- 增强柔和光影和皮肤质感。

### 身材变形

补充：

```text
身体比例自然协调，肩宽、腰线、腿部长度符合真实人体结构，手指数量正确，四肢自然，坐姿稳定，避免身体扭曲和肢体畸形。
```

### 脸太幼

补充：

```text
脸型为成熟自然的成年女性脸型，不幼态，不儿童化，五官精致但成熟，气质温柔自信。
```

### 画面太擦边

补充：

```text
整体回到高级商业人像和角色设计表达，减少身体暴露，减少暧昧氛围，强调服装、光影、姿态、人物气质和产品使用场景。
```

## 套用到电商产品图

电商产品图不是单纯人像。使用本规则时必须叠加产品主次：

- 产品仍然是主角，人物只是流量入口和场景代入。
- 不要因为追求女性吸引力而让产品变小、变糊或不在使用状态。
- 人物动作必须服务产品：手部、视线、身体方向都把注意力导向产品和使用结果。
- `性感` 类需求优先转译为：`高级女性美 + 成熟吸引力 + 自然曲线 + 合身剪裁 + 明亮商业摄影 + 产品 C 位`。
