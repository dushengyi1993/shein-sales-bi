# 当前货号类目打法

## 跨类目 Gemini 新打法

适用于空气炸锅、绞肉机、布艺清洗机、肩颈按摩器、制冰机等需要“美女 + 产品 + 场景”的封面/场景图：

- 参考图优先：如果用户会上传产品参考图，提示词不要写产品颜色和外观细节，只写产品外观严格以参考图为准。
- 电商风优先：高明度、高清晰、产品大、手机端一眼看懂；不要过暗的电影感。
- 产品与人物主次：美女负责吸睛和场景代入，产品必须在前景/C 位/手部动作焦点里，不能被人物抢走。
- “外观描述隐身”不等于产品消失：可以不写产品外观细节，但必须写清产品放在台面/前景/身体使用部位，以及产品和结果道具的主次关系。
- 动作合理：人物必须像真的在使用产品。清洁类专注刷污渍，按摩类自然佩戴或享受肩颈按摩，厨房类真实拿取食物/饮品。
- 场景边界：用户说家用就只写家庭；用户说不要车内就不要车内；用户说聚焦肩颈就不要把主要画面跑到腿部/腰部。
- 性感表达：优先用修身、真丝、罗纹、运动面料、肩颈/锁骨/腰线、明亮色彩和眼神；若平台拦截，降级为“清凉、高颜值、鲜亮、真实动作”。
- GPT Image 2 最终提示词优先用高级审美词，不直接堆“性感/诱惑/挑逗/胸/臀”：把性感意图转成成年感、成熟吸引力、健康丰腴、自然曲线、剪裁合身、得体高级、明亮商业人像。
- 风格变体可用于 A/B：明亮居家、健康运动、办公室效率、轻奢吧台、直播互动、Y2K 多巴胺、温暖治愈、前景产品霸屏。

## 咖啡机

货号示例：`SK-6810半自动意式咖啡机`、`SK-6863半自动意式咖啡机`、`SK-04031胶囊咖啡机`、`KF-JN-02便携咖啡机`。

核心场景：

- 早晨厨房。
- 办公桌。
- 露营/RV。
- 车内或差旅。

常用卖点：

- 便携、兼容、冷热、Type-C、办公室/露营/旅行。
- 只在事实确认后使用压力、容量、温度、萃取时间等参数。

禁忌：

- 不写 `BPA-Free`、`Safe`，除非用户重新确认允许且有证据。
- 不展示酒精、宗教元素。

## 吸尘器 / 布艺清洗机

货号示例：`SK-3378杆式吸尘器`、`SK-13034杆式吸尘器`，以及布艺清洗机/清洁机类目。

核心场景：

- 客厅地面。
- 沙发缝隙。
- 车内。
- 宠物毛发场景需先确认适用。
- 布艺清洗机优先：客厅浅色沙发、卧室地毯、床垫、餐椅/办公椅；如果用户限制“正常家用”，不要写车内。

常用卖点：

- 轻便、刷头、尘杯、角落清洁、续航、过滤。
- 布艺清洗机可突出污渍抽吸、透明刷头、污水箱、沙发/地毯/床垫清洁；所有除螨/杀菌/强力去污程度必须按事实。

禁忌：

- 不承诺除螨、杀菌、医用级。
- 不让人物动作假摆拍；不要一边清洁一边撩头发或举杯，动作必须专注于污渍、刷头和机器。

核心场景：

禁忌：

- 人物服装保持合规。
- 不把肩颈按摩器画成治疗颈椎病、止痛医疗器械；“pain relief”一类表达默认不用，除非平台/资料允许。

## 制冷/水壶 / 制冰机

货号示例：`PA4-6L便携式冰箱`、`S1810电热水壶`、`SK-03038制冰机`。

核心场景：

- 家庭厨房。
- 办公室。
- 露营/车载。
- 夏季饮品。
- 制冰机可做夏日派对、办公室冰咖、家庭吧台/奶茶店；沙特默认不要出现酒精饮品，微醺/鸡尾酒只在用户明确允许且目标市场适合时使用。
- 结果道具：子弹冰、冷凝水珠、柠檬薄荷水、果茶、冰咖、透明杯壁反光；这些能强化“清凉、解渴、快速出冰”的欲望感。

常用卖点：

- 容量、速度、便携、冷热/制冰、适用场景。
- 制冰机可突出快速出冰、子弹冰、双尺寸冰、低噪音、一键清洁、便携小型、冰饮场景；参数必须按用户给定。

禁忌：

- 不夸大制冰速度、保温时长、温度范围。
- 不出现酒精饮品。
- 即使 Gemini 样例出现威士忌/鸡尾酒，SHEIN 沙特默认仍要替换为果茶、冰咖、奶茶、柠檬薄荷水或无酒精派对饮品。
- 如果性感尺度导致出图失败，优先用清凉冰块、水珠、高明度色彩、夏日服装和自然笑容来保留诱惑力，不写强挑逗姿势。
