# BI Ops 2026.08.06.5

## 本机营销 Profile 分批并行

- 本机每日营销执行从逐店单开改为 3–4 店一批，默认 4 店；机器负载较高或 Profile 启动不稳时自动降为 3 店。
- 批内只允许跨店并行；同一店内的登录探针、dry-run、payload/hash 校验、execute、临时库存恢复和 live readback 仍严格串行。
- 每个店铺必须使用独立 Profile、调试端口、临时目录、救援文件、输出和租约，禁止并发写同一可变文件。
- 等整批全部店铺到终态后，逐个受控关闭本批 Profile 并确认进程、端口、租约为零，再启动下一批；单店失败不阻塞同批其它店。
- 云端晚间 fallback 仍保持每个窗口最多 1 店/1组，不随本机并发放宽。

## 生效方式

- Codex 自动化 `shein-2` 已同步新规则，后续本机营销批次直接按此执行。
- 本版只调整本机执行编排和长期文档，不改变云端 Guard、fallback timer 或 SHEIN 授权边界。
