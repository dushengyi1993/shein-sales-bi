# SHEIN BI Ops 2026.07.21.1 发布说明

Git tag：`partner-cli-v2026.07.21.1`

> “全店最低折后价”与营销价证据合并属于同日服务端热修复，不变更 Partner CLI 安装包版本；已安装 `2026.07.21.1` 的合伙人无需再次升级。

## 修复

- 修复全店链接指标组合筛选被误路由成“今日销售额”的问题。
- 修复运营会话安全提示中“也不得输出 token/cookie”被误判为索取凭据的问题。
- 链接日更分片可在业务日一致时与小时级核心数据共存，不再因生成时间不同而丢失链接指标。
- 补齐 JSH、TZZ、XC，全店查询按 19 店执行。
- 日期区间改为时区无关的日历计算，Windows/云端/GitHub Actions 输出一致。
- 修复当前营销价合并时被低优先级历史计划覆盖的问题；实时扫描的价格、当前有效标记和证据来源现在按证据等级保留。
- 增加“全店最低折后价”确定性问数：逐货号比较全部在售链接，返回最低价、并列店铺/SKC、参与取价数和快照时间，不再误用原价、供货价、计划价或历史成交价。
- 库存去化速度由“近7天70% + 近30天30%”调整为“近7天30% + 近30天70%”；页面改称“预计月销”，保留近30天真实销量并标识低样本，降低偶发单对慢销货号去化周期的放大。

## 合伙人 Skill 行为

- 销售、流量、库存、利润、售后、链接表现等只读经营数据问题必须首先使用 CLI `ask`。
- `chat` 仅用于继续自动运营会话或受控写操作。
- BI 查询失败时不允许改用浏览器、SHEIN 后台、`web-access` 或 Chrome 远程调试抓数；应原样报告 CLI 错误。

## 验收

- 确定性测试覆盖中台包装提示中的否定安全约束、真实凭据索取、全店链接指标筛选及 UTC/上海时区一致性。
- 云端使用合伙人实际 chat 包装路径和 `ask` 路径分别回读，两者必须返回同一份筛选明细。
- 合伙人实际账号通过 `/api/ops-agent/ask` 查询 7 个货号，全部返回完整跨店最低折后价；无需浏览器、远程调试或任何 SHEIN 写入。
