# 共享主机只读浏览器车道

半托与全托共用一台 2 核 8GB 主机。浏览器任务按业务副作用分为两类：

- 只读抓数、会话续期、ET 账单读取：共享持有 `/run/lock/shein-host-heavy.lock`，并独占两个浏览器槽位之一；半托优先槽位 1，全托优先槽位 0。
- 营销、库存等业务写入，以及数据库和 Portal 重物化：继续独占主机锁，不能与任何浏览器任务并发。

第二个只读浏览器只在 `MemAvailable >= 4096MiB`、标准化负载不超过 `0.65`、内存 PSI 和 IO PSI 均处于低压时启动。门禁不通过返回 75，由下一轮或定向补跑接管，不追补启动风暴。

半托下列生产任务使用 `run_host_browser_read_job.sh`：

- 19 店会话续期；
- ET forwarder 与仓储费读取；
- RTV 只读核验；
- 晨间 link/business 两个分块。

同一项目内仍通过 project/domain 锁保持串行，因此最多形成“一条半托只读浏览器 + 一条全托只读浏览器”。营销、库存写入和 Portal section worker 不进入该车道。

Portal 重 section 固定在每小时 `:14`、`:44` 尝试，每次只处理 1–2 个，并分别在 `:17/:27/:57` 前释放，避免跨越全托 `:02/:32` 首页车道。旧缓存始终原子保留。

云端 marketing-repair timer 保持停用；watchdog 仍会检查受控修复队列及其截止时间，但不再将“主动停用云端写入定时器”本身误报为生产故障。剩余写入由本地浏览器车道续办。
