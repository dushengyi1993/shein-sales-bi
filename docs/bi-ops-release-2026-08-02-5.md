# 库存状态边界与跨店售罄收紧

目标版本：`2026.08.02.5`
发布日期：2026-08-02

## 1. 修正内容

- 所有库存巡检先使用 `linksData` 四态，优先级为：已下架、待上架、已售罄、已上架；四态证据缺失时才回退到 OpenAPI 状态。
- 已下架、待上架链接不参与补库存、降库存、清零、跨店售罄或去化提醒。
- 已售罄链接仅在同店不存在同一标准货号的已上架链接时才进入库存巡检；同店已有上架同款时忽略该售罄链接。
- 跨店售罄同时要求：本链接有效售罄且库存为 0、同店无上架同款、其他店同一标准货号存在已上架且库存大于 0 的链接。
- 执行器在写前重新读取四态和同店上架同款证据，状态或证据漂移时逐条阻断。
- 每日报告与审核 Excel 单列已下架、待上架、同店有上架同款的售罄链接三类排除项。
