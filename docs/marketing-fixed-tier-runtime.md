# 用户固定三档价的受管运行标准

单一权威配置为 `config/marketing_fixed_tier_standard.json`。版本 `2026-09-08.1` 包含用户2026-09-08确认的8品：SK-GT-3065、SK-04031、SK-3378、KJ-102、SK-223、SK-7025A、BHRL-09、SK-6863。按高点击低转化、全局曝光前五/新链接、普通三档取精确 SAR 价格。型号后缀不合并，102S与3065W不在本标准内。

`lib/marketing_fixed_tier_pricing.mjs`负责统一解析、绑定与执行复验。普通活动审核、限时折扣兜底、高点击、漂移修复通过共用定价上下文消费。固定价先于ET和利润率计算；平台上限低于固定价时保留价格并阻断。分档缺指标、重复证据冲突或无法判定是否新链接时阻断，不以零代替缺失值。

后续用户明确特殊要求通过同一权威配置的 `exceptions` 记录，需包含 canonical、price、authorizedAt、authorization；可用 storeKey/SKC 缩小范围。配置修正需更新version并正式发布。普通审核文件中的旧固定价、利润率标记和任意布尔override字段不能冒充新的用户特殊要求。

候选行保存 fixedTierPricing（也保存在 lowEtFastSellerPricePullback.fixedTierPricing）中的货号、档位、价格、规则版本/文件SHA256、分层证据SHA256及证据。执行端比较最新规则及当前分层事实，变化则旧候选失效，要求受控重建。高点击登记及人工恢复链保留该绑定。现有平台限价和SKU精确价守卫继续使用，不能对固定价截价或加小数。

发布新规则不主动改动现有活动、不重新提交待回读项、不启用暂停的营销定时器。历史已提交单元仍沿原事务只读回读与恢复库存；新候选才使用当前标准。代码测试和源码存在不代表云端生效；交付须另附正式部署与云端只读验收证据。
