# 用户固定三档价的受管运行标准

单一权威配置为 `config/marketing_fixed_tier_standard.json`。版本 `2026-09-08.3` 包含用户2026-09-08确认的8品：SK-GT-3065、SK-04031、SK-3378、KJ-102、SK-223、SK-7025A、BHRL-09、SK-6863。按高点击低转化、全局曝光前五/新链接、普通三档取精确 SAR 价格。型号后缀不合并，102S与3065W不在本标准内。

`lib/marketing_fixed_tier_pricing.mjs`负责统一解析、绑定与执行复验。普通活动审核、限时折扣兜底、高点击、漂移修复通过共用定价上下文消费。固定目标先于ET和默认利润率计算。没有既有明确价格标准的货号按含仓储成本计算23%/25%/30%三档目标利润率，不覆盖已有标准。平台上限低于目标时按平台允许价报名，保留原目标、实际价、差额和实际利润率；原始商品或仓储成本缺失不得猜测。分档缺指标、重复证据冲突或无法判定是否新链接时阻断，不以零代替缺失值。

后续用户明确特殊要求通过同一权威配置的 `exceptions` 记录，需包含 canonical、price、authorizedAt、authorization；可用 storeKey/SKC 缩小范围。配置修正需更新version并正式发布。普通审核文件中的旧固定价、利润率标记和任意布尔override字段不能冒充新的用户特殊要求。

候选行保存 fixedTierPricing（也保存在 lowEtFastSellerPricePullback.fixedTierPricing）中的货号、档位、价格、规则版本/文件SHA256、分层证据SHA256及证据。执行端比较最新规则及当前分层事实，变化则旧候选失效，要求受控重建。高点击登记及人工恢复链保留该绑定。现有SKU精确价守卫继续使用。目标价不加小数扰动；平台约束可降低实际报名价，必须按最严格的SKC/SKU上限执行并保留审计。

发布新规则不主动改动现有活动、不重新提交待回读项、不启用暂停的营销定时器。历史已提交单元仍沿原事务只读回读与恢复库存；新候选才使用当前标准。代码测试和源码存在不代表云端生效；交付须另附正式部署与云端只读验收证据。

已验证的9月2日标准通过 inheritedStandards 及6个源文件SHA256入库；PA4继承含仓储45%/48%，高点击按前五商品成本利润率减2点推导，低于15%直接阻断。存在历史标准但尚未核清的货号不得套默认。默认利润率仅接受 confirmedMissingCanonicals 中绑定权威覆盖目录证据的货号；当前该清单为空，候选缺席不构成缺标准证明。
