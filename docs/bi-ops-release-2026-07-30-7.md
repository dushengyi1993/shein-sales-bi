# SHEIN BI / Ops 2026.07.30.7 发布说明

发布日期：2026-07-30

标签：`2026.07.30.7`

上一正式版本：`2026.07.30.6`

## 本版范围

- 合作方 CLI 新增结构化写入口 `operate`：由当前 Codex 明确传入动作、店铺、商品和参数，不再把写需求交给云端模型，也不依赖自然语言关键词猜动作。
- 人员写权限统一以 BI 账号 `writeStores` 为准；平台动作和店铺能力继续由 `safeWriteOperations` 独立控制，旧私有“用户名 × 店铺 × 动作”白名单退出授权链路。
- 保留完整受控写边界：真实提交前仍必须通过系统检查、锁定 `payloadHash`、取得明确确认，并在提交后完成审计和回读；CLI 的 `operate` 本身只创建任务并预检，不会静默写 SHEIN。
- 负责人规则发布权限保持独立：只有 `knowledgePublisher=true` 的负责人账号/设备可以发布规则，合伙人或同事的全店业务写权限不会获得规则修改、覆盖或发布能力。
- Partner CLI 升级到 `2026.07.30.1`，并同步更新受管 Skill 和合作方安装文档。
- watchdog 将“源码提交一致、仅有可解释维护文件”降级为维护备注，不再发送无业务影响的同步异常。
- 同步异常和 Webhook 告警改为人话摘要；移除误加的固定 20:30 通用群摘要，不改变各业务巡检原有实际时间。
- 修复营销限时折扣救援脚本在浏览器上下文误引用 Node 变量的问题。

## 验证

- 136 项确定性测试全部通过。
- CLI flow 验证结构化动作不经过云端 AI，账号只能写 `writeStores` 范围内店铺，越权店铺返回 403。
- 生产安全、复制上品、维护写、Webhook 写前闸门、Partner CLI 包、负责人规则发布与分发测试通过。
- 测试专用 Webhook 写闸门绕过仅在 `NODE_ENV=test`、显式测试开关和 loopback OpenAPI 地址三项同时成立时可用；生产 SHEIN 地址不可绕过。

## 回滚

- 源码回滚到 `2026.07.30.6`。
- Partner CLI 回滚到上一受管版本时，结构化 `operate` 不可用，但不影响 BI 网页和只读 `query`。
- 不回滚 BI 账号 `writeStores` 和 `knowledgePublisher` 数据；二者分别是业务写权限和负责人规则发布权限的事实源。
