# 电商产品 13 张套图方法论

更新时间：2026-07-16

目标：优先满足 SHEIN 沙特市场，兼顾欧洲市场，为每个店铺、每个货号生成一套可执行、可批量、可审核的 13 张产品图提示词。Amazon / noon / Temu 暂时只作为跨境电商视觉经验参考，后续真正上这些平台时再按对应平台规则单独适配。

输出重点有两种形态：

- 单张模式：每一张图都能拆出来，单独喂给作图工具生成。
- 整套模式：13 张图也能作为一个完整批次提示词，一次性喂给具备多图任务能力的工具。

## 1. 总原则

### 1.1 先事实，后创意

所有创意都必须建立在产品事实表之上：

- 产品外观事实：参考图中可见的形状、颜色、按钮、接口、配件、角度。
- 产品参数事实：尺寸、容量、功率、电压、档位、材质、配件清单。
- 产品卖点事实：用户确认、说明书确认、后台标题/参数确认、实拍可证明。
- 市场与平台事实：目标国家、语种、SHEIN 图片比例和合规边界。
- 厂家参考图：用户可提供原参考图/厂家图，作为外观、材质、角度、配件和结构的第一依据。
- 店铺风格事实：后续每个店可沉淀相对固定的画面风格、模特气质、布光、背景、色调和氛围。

19 个店铺的当前风格事实统一维护在 `config/store_style_profiles.json`，新作图和跨店上新都应先读该配置。标题/卖点资料齐全且套图与目标店风格匹配时，货号可使用 `（全）` 前缀；借用其他店或仅为近似风格的套图时，必须保留不带 `（全）` 的标准货号。

新上链接的默认标题组也统一维护在同一配置中；除非用户对当前批次另行指定，否则必须按店铺选择并作为结构化任务字段保留：

- 标题一：JSH、DL、TZZ、CX、HL、TS、TZ。
- 标题二：DX、LQ、XC、MZ、NM、YJ。
- 标题三：JY、QY、XL、FY、QH、ZL。

不得把竞品页面、其他卖家详情图、AI 推测出来的功能，直接当成本品事实。

### 1.2 一套图不是 13 张重复封面

13 张图必须分工明确：

- 封面负责点击。
- 参数图负责降低疑虑。
- 轮播图负责快速讲清核心购买理由。
- 场景图负责代入。
- 卖点图负责证明。
- 细节图负责建立质感。
- 使用/清单/对比图负责降低退货和误解。

### 1.3 产品永远是主角

人物、场景、食物、道具、文案都只是辅助，不允许抢走产品主体。

默认画面要求：

- 主体产品在画面中清楚、完整、可识别。
- 产品形状、颜色、部件不变形。
- 不确定的结构不补画。
- 参考图角度不足时，优先沿用参考图角度，不强行生成背面或内部。

### 1.4 SHEIN 沙特优先，欧洲兼顾

默认避免：

- 宗教元素、清真寺、经文、宗教化人物造型。
- 酒精、猪肉、色情低俗、明显性行为暗示。
- 医疗疗效、绝对安全、永久效果、无痛、100% 等无法证明表达。
- 中文入图。

人物风格允许更有流量感：年轻、漂亮、性感、有吸引力、轻微魅惑，必要时可向 Gemini 风格的“明亮时尚大片/高点击性感流量图”靠拢，使用更大胆但高级的深领口、露肩、锁骨、上背线条、贴身真丝/罗纹面料、直视镜头、微张嘴唇和放松但勾人的身体姿态。底线是不色情、不露点、不透视裸露、不出现明显性行为姿势、不廉价低俗，且产品必须始终是主角。欧洲市场可略微更开放，沙特市场要控制在 SHEIN 可过审的边界内。

### 1.5 阿文和英文同等重要

- 阿文和英文都不是“可选项”，都应作为主视觉文案体系的一部分。
- 阿文校对由 Codex 流程负责，可使用 reviewer/子代理或翻译复核流程，不要求用户认识阿文。
- 输出时建议同时给英文文案、阿文文案、含义说明和复核状态。
- 阿文可以直接交给图像模型生成，但成图后必须逐字核对；如果阿文变形、错位或含义不准，重新生成或修正。

## 2. 13 张图片固定架构

| 编号 | 图片类型 | 比例 | 主要目标 | 内容边界 |
|---:|---|---|---|---|
| 1 | 3:4 主封面 | 3:4 | SHEIN 主力点击图 | 产品 C 位 + 3-4 个核心卖点，明亮、手机端可读 |
| 2 | 1:1 方形封面 | 1:1 | 方图/广告/跨平台复用 | 更少文字，更强缩略图识别 |
| 3 | 参数规格图 | 3:4 | 回答尺寸/容量/功率/配件 | 只写已确认参数；缺失则留“待确认” |
| 4 | 核心轮播图 | 3:4 | 3 秒讲清为什么买 | 1 个大标题 + 3 个利益点 + 产品使用示意 |
| 5 | 主使用场景图 | 3:4 | 让买家想象自己使用 | 场景真实、产品清楚、不要偏题 |
| 6 | 第二使用场景图 | 3:4 | 展示另一个高频场景 | 与第 5 张不能重复 |
| 7 | 卖点图 1 | 3:4 | 证明最强卖点 | 用图中图/箭头/局部特写解释 |
| 8 | 卖点图 2 | 3:4 | 证明第二卖点 | 用场景和结果表达，避免空话 |
| 9 | 细节特写图 | 3:4 | 建立质感和可信度 | 接口、按钮、刀头、喷头、杯体等可见细节 |
| 10 | 使用步骤图 | 3:4 | 降低上手门槛 | 3-4 步，短文案，不脑补不可见步骤 |
| 11 | 尺寸/容量/适用范围图 | 3:4 | 降低预期偏差 | 尺寸、容量、适用人数/空间/食材等必须有来源 |
| 12 | 痛点解决/对比图 | 3:4 | 强化购买理由 | 可做“before/after 示意”，禁止伪造极端效果 |
| 13 | 配件/清单/信任图 | 3:4 | 说明到手包含什么 | 只展示随货物品；默认不展示包装盒 |

当前默认只按 SHEIN 沙特/欧洲口径生成；Amazon / noon / Temu 只作为视觉经验参考。只有明确要上 Amazon / noon 时，才额外生成对应平台的白底合规主图作为替换封面，不占默认 13 张。

文字处理原则：

- 图像模型可以直接生成最终文案、参数、数字、单位、型号、阿文和小字号；不默认限制为无字底图。
- `overlay_metadata` 用作逐字复核清单：成图后核对 `Type-C`、容量、功率、尺寸、阿文等是否准确清晰。
- 如果某张图的文字出错、变形或不清晰，再用后期工具修正；Amazon / noon 主图仍不允许有文字和图标。

## 3. 每张图的提示词结构

每张图都使用同一结构，便于批量化：

```text
图片编号：
图片用途：
比例：
平台/市场：
画面目标：
产品外观锁定：
可使用事实：
场景与构图：
人物/道具：
文案层：
光线与风格：
负向约束：
最终提示词：
审核要点：
```

整套模式要在 13 张逐张提示词前增加一段总控提示词：

```text
请为同一个产品生成 13 张 SHEIN 电商产品图。所有图片保持同一产品外观、同一店铺风格、同一色调和同一视觉质量；每张图的主题不同，不要重复构图。除第 2 张为 1:1，其余均为 3:4。英文和阿文同等重要，文字必须清晰、准确、手机端可读。产品参考图是外观唯一依据，不得改变产品形状、颜色、接口、配件和比例。人物风格可以高级性感、有吸引力、轻微魅惑，必要时加大到明亮时尚大片式的性感流量风，但不能色情低俗，产品必须始终是主角。
```

### 3.1 产品外观锁定模板

```text
以用户上传的参考图为唯一产品外观依据。保持产品本体、配件、按钮、接口、颜色、比例、材质观感和可见角度一致；不要改变产品形状，不要发明参考图中不可见的结构。若无法确定背面、内部或隐藏部件，保持参考图角度，不要自行补画。
```

### 3.2 文案层规则

图上文字必须短、可读、可审核：

- 封面：1 个主标题 + 2-4 个短卖点。
- 参数图：字段化表达，避免长句。
- 卖点图：每张只讲一个核心点。
- 阿文：和英文同等重要，可以直接入图；由 Codex 负责翻译和复核，必要时调用 reviewer/子代理做阿文校对。
- 禁止：价格、限时、最便宜、第一、100%、永久、安全保证、医疗疗效。

### 3.3 负向约束模板

```text
不要出现中文；不要出现包装盒；不要出现宗教元素、清真寺、经文、宗教化人物造型；不要出现酒精、猪肉、色情低俗或明显性行为暗示；不要出现未确认认证、医疗疗效、绝对化承诺；不要添加未包含配件；不要改变产品形状、颜色和结构；不要让文字变形乱码；不要出现竞品品牌、水印、价格、促销标签。
```

## 5. 风格系统

### 5.1 默认 SHEIN 沙特电商风

- 高明度、高清晰度、背景干净。
- 产品主体大，人物和场景辅助。
- 色彩可鲜亮，但不要廉价荧光感。
- 文案大字少，图标清楚。
- 场景本地化但不宗教化：现代厨房、客厅、办公室、汽车、露营、家庭聚会、梳妆台、健身后恢复等。
- 需要流量感时，可加入“高级性感美女/轻微魅惑/适当露肤/深领口/露肩锁骨/贴身真丝或罗纹面料/直视镜头/微张嘴唇/放松但勾人的姿态”；底线是不色情、不露点、不透视裸露、不明显性行为姿势、不低质廉价擦边，且产品必须压过人物。

### 5.2 参考图优先与产品主次

- 如果用户会上传厂家图/产品参考图给作图工具，提示词默认不要手写产品颜色、结构、按钮、接口、窗口形状等外观细节，只写“产品外观严格以参考图为准”。
- 这叫“外观描述隐身”，不是“产品视觉隐身”：产品仍然要大、清楚、在前景/C 位/手部动作焦点或身体使用部位中。
- 美女模特是流量入口，不是唯一主角。产品应位于前景、C 位、手部动作焦点或高亮区域，人物视线/动作要把注意力带回产品。
- 可用“结果道具”强化转化，例如制冰机配冰块、水珠、果茶/冰咖，空气炸锅配酥脆食物，清洁机配污渍抽吸过程；结果道具必须服务产品，且不引入沙特禁忌或未确认配件。
- 使用动作必须真实：清洁类专注刷污渍，按摩类自然佩戴或享受肩颈按摩，厨房类真实取食物/饮品；不要为了性感写出不合理摆拍。
- 用户给了场景边界必须遵守，例如“正常在家里使用，不要汽车”“还是凸出肩颈按摩”，不能为了丰富画面擅自跑偏。
- 如果作图平台因尺度失败，先收敛高风险词和姿态，保留高颜值、鲜亮明快、修身材质、清透光线和真实使用动作，优先保证能出图。
- 对 GPT Image 2 这类更容易拦截直白欲望词的模型，最终提示词要把“性感/火辣/诱惑/撩人”改写为“高级女性美/成熟吸引力/健康丰腴/自然曲线/得体合身剪裁/明亮商业人像”等审美词。

### 5.3 GPT Image 2 友好写法

核心不是把图做保守，而是把“低俗直白的欲望词”换成“高级商业审美词”：

| 不建议直接写 | 更稳定写法 |
|---|---|
| 性感 | 高级女性美 / 成熟吸引力 |
| 魅惑 / 撩人 | 眼神有故事感 / 有吸引力但克制 |
| 身材火辣 | 健康丰腴 / 身形圆润匀称 / 自然曲线 |

| 贴身 | 剪裁合身 / 版型贴合 |
| 低胸 / 透明 / 衣服滑落 | 得体高级 / 材质柔软有质感 |
| 昏暗暧昧 / 私房 | 明亮室内 / 干净自然光 / 高级商业人像 |

改写公式：

```text
敏感欲望词 -> 气质词 -> 整体体态 -> 得体服装 -> 明亮商业场景 -> 商业镜头 -> 安全边界
```

案例里可复用的完整写法顺序：

```text
图像任务声明 -> 主体与构图 -> 成年身份与气质 -> 姿态和整体体态 -> 脸部/发型/妆容 -> 服装剪裁与材质 -> 场景和光影 -> 产品回收 -> 成图质量 -> 负向边界
```

电商迁移原则：

- 案例提示词很细，值得学；但人像案例里的床上私密感、泳装湿身、女仆/猫耳、低机位身体凝视不能直接搬到 SHEIN 图里。
- 要把这些元素转成明亮商业摄影、真实可购买服装、产品 C 位、平视或微俯视商业镜头、真实使用动作。
- 每段人物描写最后都要回收产品：产品要清楚、较大、在前景/C 位/手部动作焦点中，人物视线和动作要把注意力带回产品。
- 除非明确要求 CG / 插画，否则默认使用真实商业摄影质感：自然皮肤纹理、轻微真实瑕疵、真实布料褶皱、可信手部动作，避免 3D CG 假人感、塑料皮肤、AI 娃娃脸和蜡像感。
- KSA 默认高安全得体版：用成年气质、妆发、材质、合身但得体的剪裁、自然姿态和产品互动体现吸引力；默认避免内衣感、透视、湿身、露腹、极深领口、超短裙、过紧 bodycon、低机位身体凝视和身体局部特写。用户明确要求更大胆时，也通过明亮时尚感和产品 C 位来加流量，不通过更多裸露来加尺度。

## 6. 类目策略

### 6.1 咖啡机类

适用：`SK-6810半自动意式咖啡机`、`SK-6863半自动意式咖啡机`、`SK-04031胶囊咖啡机`、`KF-JN-02便携咖啡机`。

图组重点：

- 封面：咖啡出品、操作便利、家庭/办公室/旅行场景。
- 场景：早晨厨房、办公室、露营、车内/RV。
- 卖点：兼容方式、加热/冷热、Type-C、便携、萃取口感等必须按事实表使用。
- 参数图：水箱、杯量、电源、胶囊/咖啡粉兼容性、尺寸。
- 禁忌：不要虚构压力 bar、温度、认证、BPA-Free、Safe。

### 6.2 电动缝纫机类

适用：`SM-505A电动缝纫机`、`SM-520A电动缝纫机` 等。

图组重点：

- 封面：新手友好、家庭修补、DIY。

- 卖点：线迹数量、双速、脚踏、照明、切线、便携等按事实使用。
- 参数图：尺寸、重量、电源、适用布料、配件。
- 禁忌：不要展示工业厚料、皮革等未确认能力。

### 6.3 吸尘/清洁类

适用：`SK-3378杆式吸尘器`、`SK-13034杆式吸尘器`、`SK-13065吸尘器`。

图组重点：

- 封面：轻便、强吸、地面/缝隙/沙发多场景。
- 场景：客厅、车内、沙发、厨房地面。
- 卖点：刷头、尘杯、续航、过滤、低噪等必须有事实来源。
- 禁忌：不要承诺除螨、杀菌、医用级净化。

### 6.4 蒸汽熨烫类

适用：`SK-GT-3065蒸汽熨烫机`、`SK-11004蒸汽熨烫机`、`SK-11041蒸汽熨烫机`。

图组重点：

- 封面：快速除皱、上班前、旅行衣物护理。
- 场景：衣柜、挂烫、旅行箱、办公室前准备。
- 卖点：蒸汽量、水箱、预热、便携、适用面料。
- 禁忌：before/after 必须写“visual demonstration”，不要伪造极端皱褶消失效果。

### 6.5 绞肉/料理/早餐类

适用：`SK-7025A绞肉机`、`SK-7027绞肉机`、`KJ-102三明治机和早餐机`、`JD-389空气炸锅`。

图组重点：

- 封面：食物成品诱人，但产品仍清楚。
- 场景：家庭厨房、早餐、聚会备餐。
- 卖点：容量、刀头、易清洁、多功能、定时/温控。
- 禁忌：不要出现猪肉、酒精；健康类表达要克制。

### 6.6 个护类

适用：`FZ-666颈部按摩器`、`BHRL-09激光脱毛仪`、`SK-1914热风梳`、`SK-15013卷发钳和卷发棒`。

图组重点：

- 封面：人物使用 + 产品贴合部位/造型效果。
- 场景：办公室、卧室、梳妆台、健身后恢复、车内差旅。
- 卖点：档位、温度、便携、使用部位、造型效果。
- 禁忌：不得医疗化；不得过度暴露；脱毛类不能说永久、无痛、医疗级。

## 7. 评分机制

每张提示词按 100 分评价：

| 维度 | 分值 | 说明 |
|---|---:|---|
| 产品事实准确 | 25 | 不改外观、不混竞品参数、不用未确认卖点 |
| 平台/市场合规 | 20 | 比例、文案、禁忌、人物尺度、无水印价格等 |
| 图像可执行性 | 15 | 单张图目标清晰，AI 能按图执行 |
| 转化力 | 15 | 第一眼吸睛，痛点明确，文案短促有力 |
| 信息分工 | 10 | 13 张图互补不重复 |
| 手机端可读性 | 10 | 文字少、对比强、主体大 |
| 后续可维护 | 5 | 输出结构化，便于网站/API 接入 |

硬性一票否决：

- 引入竞品独有功能或参数。
- 改变产品颜色、形状、部件。
- 使用禁用词或无法证明的绝对承诺。
- 包含明显不适合沙特市场或平台审核的内容。

### 8.1 输入

```json
  "visual_facts": [
    "产品形状、颜色、部件以参考图为准"

  "forbidden_visuals": ["包装盒", "宗教元素", "清真寺图案"],
```

### 8.2 输出

- `review_checklist`：审核要点。
- `blocked_claims`：未确认但常见、需要用户补资料确认的候选卖点。

### 8.3 文件命名

```text

```

## 9. 未来接入 SHEIN API / 网站的设计

### 9.1 数据触发

未来从 SHEIN API 或本地 BI 读取：

- 曝光高、点击低：优先换封面图。
- 点击高、转化低：优化参数图、卖点图、信任图。
- 退货/差评集中：补尺寸、使用限制、配件清单、真实场景。
- 同款多链接表现差异大：学习赢家链接的图片结构，但不复制素材和事实。
- 新品无评论：加强参数、场景、使用步骤、清单图。

### 9.2 网站接口

建议网站提供四个模块：

1. 产品事实库：参数、卖点、参考图、禁用项。
2. 套图生成器：按货号/店铺生成 13 张提示词。
3. 提示词评分器：独立 reviewer 评分和挑错。
4. 作图任务队列：把每张图提示词送到免费工具，多任务并行。

### 9.3 人工边界

- AI 可以生成提示词和评分建议。
- AI 不自动确认未证实参数。
- AI 不自动把竞品内容写入本品详情。
- 阿文由 Codex/reviewer/子代理负责翻译与复核；合规敏感词、医疗/认证类表述必须在输出前复核。

## 10. 当前推荐推进顺序

1. 先选 3 个样例货号：`KF-JN-02便携咖啡机`、`SM-505A电动缝纫机`、`SK-3378杆式吸尘器`。
2. 每个货号各整理一份产品事实表。
3. 用 skill 生成 13 张提示词。
4. 用 reviewer rubric 评分。
5. 用免费工具并行出图。
6. 回收出图结果，记录“提示词 -> 成图问题 -> 修订策略”。
7. 再扩大到所有高优先级货号。
